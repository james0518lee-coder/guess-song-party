# 猜歌俱樂部

本機 MP3 猜歌遊戲。題庫包：華語經典、華語流行、華語新歌、台語歌、男歌手、女歌手、團體、抖音神曲、嘻哈金曲、對唱組合、隨機。

## 使用方式

1. 開啟 GitHub Pages 網址。
2. 到「我的題庫」按「載入設定」，選擇題庫設定 JSON。
3. 按「匯入資料夾」並選取本機音樂資料夾（音檔會保存在此瀏覽器，下次自動還原）。
4. 回到「開始猜歌」，選擇題庫包、題數、播放段落及秒數，按「建立比賽題庫」後開始。

## 抽題規則

- 男歌手、女歌手、團體：依歌曲數量加權，單一歌手／團體最高 8%，超出比例加到「其他」。
- 嘻哈金曲：完全隨機。
- 其餘題庫包（含隨機）：每首歌機率相同，單一歌手最高 8%。
- 播過的歌不會重複，全部播完後自動重置。

## 其他

- 歌手顯示：優先用「歌手」欄，沒填時用資料夾名稱（其他除外）。
- 隊伍分數會保存在瀏覽器；可移除隊伍或將分數歸零。
- 「清除未使用的音檔」可刪除不在題庫清單內、但仍佔用瀏覽器空間的音檔。

音樂只在使用者裝置本機播放，不會上傳到網站或 GitHub。
